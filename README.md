## 📝 참여 방법 (5분 컷)

### 1. 이 페이지에서 [`capsules/`](./capsules) 폴더 진입

### 2. `Add file` → `Create new file` 클릭

### 3. 파일명 입력

```
capsules/본인이름.md
```

예) `capsules/정유경.md`

### 4. 아래 양식 복사해서 내용 채우기

```markdown
## 🧑‍💻 [이름] · [부서]

### 🤖 AI 사용 첫 성공담
(오늘 Claude로 시도해본 거 또는 평소 AI로 해결한 일 1개)

### 💬 강사·동료에게 한마디
(자유롭게, 농담 환영)
```

### 5. 페이지 하단으로 스크롤

- 초록 버튼 **`Propose new file`** 클릭
- 다음 화면에서 **`Create pull request`** 한 번 더 클릭 = **끝!**
