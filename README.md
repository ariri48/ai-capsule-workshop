## 📝 이렇게 하면 돼요 (4단계)

### 1️⃣ 두레이 핀 메시지의 링크 클릭
이 페이지로 이동 → 위쪽 `capsules` 폴더 클릭

### 2️⃣ 우측 상단 초록색 `Add file` → `Create new file` 클릭

### 3️⃣ 파일명에 본인 이름 입력
```
본인이름.md
```
예시: `정유경.md`

### 4️⃣ 아래 양식 복사해서 채우기 → 하단 초록 버튼 두 번 클릭 = 끝!
